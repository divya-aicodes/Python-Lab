# Python Lab

This repository contains four introductory Python programming labs. Each lab is kept in a separate folder with its own source code and instructions.

| Lab | Title | Program |
| --- | --- | --- |
| 1 | Student Information and Academic Summary | [`student_information.py`](lab-01-student-information/student_information.py) |
| 2 | Scientific Calculator for Two Numbers | [`scientific_calculator.py`](lab-02-scientific-calculator/scientific_calculator.py) |
| 3 | Mathematical Calculator Using Built-in Functions and the Math Module | [`mathematical_calculator.py`](lab-03-mathematical-calculator/mathematical_calculator.py) |
| 4 | Electricity Bill Generator | [`electricity_bill.py`](lab-04-electricity-bill/electricity_bill.py) |

## Requirements

- Python 3.10 or newer
- No third-party packages

## Running a lab

Open a terminal in the repository and run the required program. For example:

```bash
python lab-01-student-information/student_information.py
```

On Windows, `py` can be used instead of `python` if that is how Python is installed.
