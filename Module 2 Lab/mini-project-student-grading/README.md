# Mini Project: Student Grading Automation

## Objective

Accept a student's details and subject marks, then automatically calculate the total, average, result, and grade.

## Grading scale

| Average | Grade |
| --- | --- |
| 90-100 | A+ |
| 80-89.99 | A |
| 70-79.99 | B |
| 60-69.99 | C |
| 50-59.99 | D |
| Below 50 | F |

A student must score at least 40 in every subject to pass. A failed student receives grade F regardless of the average.

## Run

```bash
python student_grading.py
```
