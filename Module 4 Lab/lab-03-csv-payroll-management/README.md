# Lab Exercise 3: CSV-Based Payroll Management System

## Objective

Store employee payroll details in a CSV file and generate a report containing gross pay, deductions, and net pay.

The program supports adding, deleting, and displaying employees. `payroll.csv` is created automatically beside the program.

## Calculation

- Gross pay = basic salary + allowance
- Deduction = gross pay × deduction percentage
- Net pay = gross pay − deduction

## Run

```bash
python payroll_management.py
```
