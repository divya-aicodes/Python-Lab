# Lab Exercise 1: Log File Reader

## Objective

Read a text log file safely, display its contents with line numbers, and summarize the number of lines, words, characters, warnings, and errors.

The reader reports missing files, directories, invalid text, and other file-access errors without crashing.

## Run

```bash
python log_file_reader.py
```

Enter the path of any UTF-8 text log file when prompted.
